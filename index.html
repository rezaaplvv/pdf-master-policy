Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: 11 September 2026

Aplikasi PDF Master ("kami") menghargai dan berkomitmen untuk melindungi privasi pengguna kami. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi Anda saat menggunakan aplikasi mobile PDF Master.

1. Pengumpulan dan Pemrosesan Dokumen

Aplikasi PDF Master adalah alat produktivitas utilitas dokumen. Seluruh proses pengolahan file dokumen PDF, penggabungan, pemotongan, tanda tangan digital, dan konversi dokumen dilakukan secara lokal di perangkat Anda. Kami tidak menyimpan atau mengunggah dokumen pribadi Anda ke server pihak ketiga tanpa persetujuan eksplisit Anda.

2. Izin Perangkat yang Digunakan

  • Kamera (Camera): Digunakan semata-mata untuk fitur pemindaian dokumen fisik (Document Scanner) secara langsung menjadi file PDF.
  • Penyimpanan (Storage / Media): Digunakan untuk membaca file dokumen atau gambar yang Anda pilih serta menyimpan file hasil olahan PDF ke memori perangkat Anda.
  • Notifikasi (Notifications): Digunakan untuk memberikan informasi pembaruan penting, fitur baru, dan pengumuman aplikasi melalui layanan push notification.

3. Layanan Pihak Ketiga

Aplikasi kami menggunakan layanan pihak ketiga yang terpercaya untuk mendukung fungsi aplikasi:

  • OneSignal & Google Firebase Cloud Messaging (FCM): Digunakan untuk pengiriman push notification. Layanan ini dapat mengumpulkan pengenal perangkat unik (Device ID) untuk keperluan pengiriman pesan.

4. Keamanan Data

Kami menerapkan standar keamanan terbaik untuk memastikan integritas dan privasi data Anda selama menggunakan aplikasi PDF Master.

5. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Setiap perubahan akan dicantumkan pada halaman ini.

6. Hubungi Kami

Jika Anda memiliki pertanyaan mengenai Kebijakan Privasi ini, Anda dapat menghubungi kami melalui email dukungan pengembang.
