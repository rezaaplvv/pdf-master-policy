## Policy Overview
PDF Master is an all-in-one PDF productivity and document utility application designed with a strict offline-first, local-processing architecture.

### Key Privacy Highlights:
- **Local Document Processing:** All PDF operations (Merge, Split, Compress, Convert, Annotate, Digital Sign, Crop, and Redact) are executed 100% locally on the user's device. No user documents are transferred or stored on external servers.
- **Camera Access:** Used exclusively for capturing physical documents via the built-in Document Scanner feature.
- **Storage & Media Files:** Used solely to read user-selected files and store the resulting processed PDF documents on the device.
- **Push Notifications:** Powered securely by OneSignal and Google Firebase Cloud Messaging (FCM) to deliver product updates and announcements.
