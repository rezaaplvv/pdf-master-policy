## Overview
PDF Master is an all-in-one PDF productivity and document utility application. This privacy policy outlines our data handling practices in compliance with Google Play Store developer guidelines:

- **Local Document Processing:** All PDF operations (Merge, Split, Compress, Convert, Annotate, Sign) are performed locally on the user's device.
- **Camera Permission:** Used exclusively for the built-in document scanning feature.
- **Storage / Media Access:** Used solely to read selected input files and save output documents to local storage.
- **Push Notifications:** Handled securely via OneSignal and Google Firebase Cloud Messaging (FCM) for application updates.
